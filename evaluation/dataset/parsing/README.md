# parsing-v1 fixtures

Ten synthetic resume documents are provided as five text-layer PDFs and five DOCX files. Ten
natural-language job descriptions are provided as UTF-8 text files. `cases.json` is the expected
structured-output contract used by the deterministic validation runner.

These fixtures contain no real personal data. They are not a scan/OCR set and are not used to
claim real-provider LLM parsing quality.
