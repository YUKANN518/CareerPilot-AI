# Interview Basics

This synthetic guide is provided only for the CareerPilot demo knowledge base.

For behavioural questions, describe the situation, your responsibility, the action you personally took and the result. For technical questions, state assumptions, explain trade-offs and verify edge cases. If you do not know an answer, explain how you would investigate it instead of fabricating certainty.

Practice with time limits, then review whether each answer is specific, relevant and supported by real experience.
