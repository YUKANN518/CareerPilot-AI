# Resume Guidelines

This synthetic guide is provided only for the CareerPilot demo knowledge base.

Use concise achievement statements that name the task, action and observable result. Skills should be supported by project, work or education evidence. Keep facts accurate: an optimization tool may improve wording and ordering, but it must not invent employers, dates, degrees, certifications or metrics.

Tailor the summary and evidence order to the target role. Preserve an original resume version so every accepted change can be reviewed.
